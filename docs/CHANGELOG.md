# Changelog

One line per task card, newest first.

## Unreleased

- M0 spike: tools/spike/fake and smoke_fake.py, a fake OneNote that runs every spike script end to end on any platform in happy and fallback modes.
- Measure: Sfp.Core.Pdf.PdfGeometryDump returns every word (text, x, baseline, top, bottom, right, size, font) and line-like segment of PDF pages in points with a top-left origin, PdfGeometryTable prints them; sfp-measure <pdf> [page ...] (default 1 13 16 17 24) and the measure verb (src/Sfp.Cli/Verbs/MeasureCommand.cs, --pdf, --pages) print the dump; tested on generated PDFs.
- M5.5 Failure handling: CalendarImportRunner fetches each calendar source on its own and skips failures, FailureCounter (sfp-refresh-failures.json beside the sidecar) counts consecutive total failures and raises a toast at three through ISourceFailureNotifier (Windows PowerShell toast stub), AllSourcesFailed flags exit code 6.
- M5.3 Freeze and diff: CalendarDiff turns placed slot texts into only the Create, Update and Remove writes needed, never touches days on or before FrozenThrough (at least yesterday) or past the horizon, and returns the new FrozenThrough.
- M5.2 Placement engine: PlacementEngine maps events to daily time-block rows with continuation lines, the all-day band, weekly overview columns (18-line cap) and monthly cells (2-line cap), cutting titles to the manifest widths with an ellipsis.
- M5.1 Calendar sources: IcsCalendarSource (Ical.Net 5, recurrences expanded, local-time normalized, private masked, cancelled flagged), HolidayCalendarSource from templates/holidays-us.json, OutlookCalendarSource behind a feature check, CalendarSourceFactory and the Setup line parser.
- M4.1 Page reader: PageXmlParser parses GetPageContent XML into PageXml (outlines with position, size and z, text runs as HTML and plain text, ink words with recognizedText, images, meta, page id and title); PageXmlInk reads one:InkDrawing bounds; hand-written Setup page fixture finds a typed run and an inked word by rectangle through PageXml.OutlinesIn.
- M3.2 Page XML builder: PageXmlBuilder (page settings, sfp.key meta, title, locked sheet outline at the title offset, one styled outline per link or propagated anchor with opacity blended color), HierarchyXmlBuilder (section pages per the PRD appendix), ContentsXmlBuilder (nested native links outline), HyperlinkParser and ColorHex; every output validates against a reconstructed 2013 schema subset under a strict callback; Verify snapshot of the Mon Jan 4 page XML with image data elided.
- M3.1 COM wrapper: IOneNoteApp and OneNoteApp, late-bound OneNote.Application on one dedicated STA thread, every call timed and logged (no image data, XML cut to 200 chars), retried once after 2 s on RPC_E_CALL_REJECTED or RPC_E_SERVERCALL_RETRYLATER, COM failures mapped to OneNoteUnavailableException, OneNoteXmlRejectedException (carrying the XML), OneNoteBusyException or OneNoteException with the HRESULT; Category COM integration test lists notebooks on a Windows PC and skips elsewhere; scheduler and retry rule unit-tested on Linux through an injected fake target.
- M2.3 Overlay primitives: SheetCanvas draws in PDF points scaled by dpi/72 (erase, fill, rect outline, text with left/center/right alignment and opacity, circle, rule, text width and metrics in points, pixel probes); PngEncoder writes opaque 24-bit RGB PNGs (Rgb888x, IHDR color type 2) deterministically; tests at 72 and 220 DPI assert pixel colors at known points; golden hash convention documented in tests/Sfp.Render.Tests/golden/README.md.
- M2.2 Font service: FontService loads the manifest family through SKFontManager or an injected font directory list, refuses a substituted family with FontSubstitutionException, falls back to the bundled TeX Gyre Bonum files with a warning, and creates SKFonts at pixel size with antialiasing, subpixel positioning and no hinting; DigitWidth and TextWidth in points; FontFixtures renames a bundled face so tests can simulate an installed Bookman Old Style.
- M2.1 Rasterizer: PDFium rendering through PDFtoImage with explicit pixel sizes (3398 x 2353 at 220 DPI), antialiasing on, no annotations or form fill, manifest background, an LRU page cache keyed by (path, page, dpi) handing out copies; ColorParser for #RRGGBB; shared test fixtures: the 132-page synthetic template built from the manifest with PdfPig, a manifest loader for tests, and an OCR helper (tesseract CLI or python3 tesserocr) with crop and normalize.
- M1.5 Date engine: month grids: Grid and GridWithMode give the 5 by 7 Monday-first grid with real dates in every cell, InMonth and InQuarter flags, six-row overflow stacked on the row-5 cell of the same weekday (StackedDay, StackedDate) or dropped; tests for January 2027, November 2026, March 2026, August 2026, March 2027, October 2026 and the 18 months of the reference quarters.
- M1.4 Date engine: quarter and weeks: DateEngine implements Build, Weeks and WeekOf per the PRD formulas with range validation and the Qn or month-span label; PlannerText holds every date-derived string (date slot fields in either order, DayTitle, ShortDate, LongDate, MonthYear, WeekNumber, WeekSectionName, CoverLines, DayCounter, token values) in InvariantCulture; tests cover Q1 2027, Q2 2024, Q4 2026, Q1 2024, the off-cycle labels, the year limits and all 60 starts of 2024 to 2028.
- M1.3 PDF validation: ManifestValidator checks the page count, every page size within 1 pt and a text probe per page type with PdfPig and reports the PRD messages; a missing or unreadable file is an error, not an exception; PdfFixtures generates template-like PDFs from the manifest for the 131-page, wrong-size and missing-probe tests.
- M1.2 Manifest model and loader: ManifestLoader (LoadShipped, Load, Merge of a user manifest over the shipped one key by key, shared read-only JsonOptions), TokenExpander (Validate, Expand), ManifestChecks (structural sanity and PRD token validation at load), PageNames; round-trip, unknown-token and merge-over tests.
- M0.9 Manifest offsets: m0_9_apply.py patches titleOffsetPt, pageColor, anchorPaddingPt and anchorUnderline in place in the manifest's onenote block from findings.json decisions, proposals or --set, with --dry-run and --selfcheck.
- M0.8 Ink read-back: m0_8_ink.py prints every one:InkWord and its recognizedText from the inked page and saves scratch/m0_8-page.xml as the M4.1 fixture.
- M0.7 iPad check: m0_7_ipad.md, the manual checklist for the OneDrive move and the seven iPad checks, plus the word to ink for M0.8.
- M0.6 Page metadata: m0_6_metadata.py writes one:Page dateTime, one:Meta sfp.key (schema order first, then after PageSettings) and one:Section color, syncs, optionally reopens, and reports which persisted.
- M0.5 Hotspot alternative: m0_5_hotspot.py places a transparent 1 x 1 PNG with the one:Image hyperlink attribute over the baked day number (outline shape, then direct image shape) and records click, visibility and selectability.
- M0.4 Link anchors: m0_4_anchors.py adds the three styled link anchors from the manifest links block plus two labelled variants, prints the XML back with kept and dropped attributes and position deltas, and proposes anchorPaddingPt and anchorUnderline.
- M0.3 Subpage levels: m0_3_levels.py sets pageLevel 1, 2, 2 in a changed order through UpdateHierarchy, reads it back, and records whether UpdateHierarchy creates ID-less pages.
- M0.2 Background image page: m0_2_background.py writes the test sheet as a locked background at y = 0, 36 and 48 with the hex page color and automatic, reads each page back, and proposes titleOffsetPt and pageColor.
- M0.1 COM reachability: spike_common.py (OneNote wrapper with retry, hierarchy and page helpers, PRD XML builders, findings printer, 220 DPI test sheet with --selfcheck), m0_1_com.py (ProgIDs, version, 2013 namespace, open notebooks), tools/spike/README.md and the How the scripts report paragraph in docs/spike-findings.md.
- M1.1 Solution skeleton: Sfp2OneNote.sln with Core, Render, OneNote, Refresh, Cli, App, TestSupport, four test projects and the measure tool; Directory.Build.props (nullable, warnings as errors, analyzers), central package versions, CI on Windows and Linux, dependency-direction test, core contracts, the manifest, the bundled TeX Gyre Bonum fallback font and the US holiday list.
