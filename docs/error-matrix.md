user-facing text, the outcome, and the test that exercises it. Line numbers are as of the wave-3 integration; search
for the quoted strings if they move. Exit codes come from src/Sfp.Cli/ExitCodes.cs: 0 success, 2 validation error,
3 OneNote unavailable, 4 render error, 5 write error, 6 refresh source unreachable.
