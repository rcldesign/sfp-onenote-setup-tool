# Error matrix (M7.1)

Every row of the PRD's "Error handling" table and every Refresh case, mapped to where it is detected, the exact
user-facing text, the outcome, and the test that exercises it. Line numbers are as of the wave-3 integration; search
for the quoted strings if they move. Exit codes come from src/Sfp.Cli/ExitCodes.cs: 0 success, 2 validation error,
3 OneNote unavailable, 4 render error, 5 write error, 6 refresh source unreachable.

## Open items (wave 3 fix round)

- Disk full: the PRD asks for a message with the free space needed; the code reports the raw IOException text. Fix: detect ERROR_DISK_FULL / ERROR_HANDLE_DISK_FULL (HResult 0x80070070, 0x80070027) and ENOSPC and report "Not enough disk space in {folder}: about {n} MB is needed for {pages} pages at {dpi} DPI." with the size estimate the app shows.
- Render error wording: the PRD says "nothing written to OneNote"; the notebook shell (notebook, sections, empty pages) exists before rendering starts because page ids must exist before any content is written. No page content is written; recorded in decisions.
- Tests missing for: the render-only verb's exit-4 branch, the partial calendar failure warning text, the moved tool-owned object on the calendar path, the 60-second notebook open timeout, Refresh cancellation (exit 5 with "Cancelled.").
- OneDrive warning wording differs between the preflight and the form; use one text.
